# InspectWise

InspectWise is a full-stack training application designed for building inspectors and processors, combining construction industry knowledge with interactive digital learning.

## Key Features

- Responsive React interface with reusable components
- Interactive inspection workflows
- Learning progress tracking
- Live weather integration
- AI-assisted learning using the Gemini API
- Supabase/PostgreSQL vector search integration

## Technology Stack

- **Frontend:** React, JavaScript, HTML, CSS
- **Backend:** Node.js, Express
- **Database:** Supabase / PostgreSQL
- **AI Integration:** Gemini API

## Project Background

Developed as a software engineering mini-project through the University of Canterbury / Institute of Data programme.

InspectWise demonstrates the application of full-stack development, UX/UI design, system workflows and construction industry knowledge to a practical training product.

## Project Structure

- `client/` — React frontend
- `server/` — Express backend

## Project Status

Completed software engineering mini-project. Source code is provided for portfolio and technical review.
